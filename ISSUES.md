# Issues

Use [this fork's issue tracker](https://github.com/r-melvin/Cataclysm-DDA-3D/issues/new/choose) to report bugs, ask questions, or suggest improvements.

Give the issue a short title and describe it in your own words. That's all you need to submit a report.

Screenshots, steps to reproduce, your branch or game version, and save files can help us investigate, but they are optional. You can add them later if needed.
